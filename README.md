# Area clienti — Assetto Impresa

Area riservata dello studio del Dott. Giuseppe Antonio Marotta (assettoimpresa.com): i clienti caricano estratti conto, fatture, note contabili e presenze; lo studio pubblica F24, bilanci, dichiarazioni e cedolini.

- `index.html` — accesso dei clienti (password + codice via e-mail, primo accesso, recupero password)
- `area.html` — area del cliente: bacheca, caricamento con rinomina automatica, documenti dallo studio, profilo
- `studio.html` — console dello studio: arrivi da registrare, clienti, richieste, scadenze, registro
- `apps-script/` — servizio Google Apps Script (archivio su Drive, dati su Fogli)

Installazione: vedere [GUIDA.md](GUIDA.md).
